# SOP 录制

Chrome / Edge 插件。在网页上照常点击、输入、跳转，自动生成带截图的步骤文档。

录的是浏览器里的页面，例如智马翻译工作台。微信、桌面软件不在录制范围内。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 打开「开发者模式」。
3. 选「加载未打包的扩展程序」，指向本目录 `sop-plugin`。
4. 把插件固定到工具栏。

## 使用

1. 点工具栏图标，打开侧边栏。录制、说明和导出按钮固定在最下面，步骤列表在上面滚动。「侧边栏样式」可以换浅紫、浅色、深色或高对比，也可以改背景、文字、强调色、字号、间距、行距、圆角和透明度。透明度 0% 是实色，往右调整栏变淡，能透出浏览器侧栏的底色。标题、步骤标题和说明各自有颜色、字号和粗细。流程说明和每一步的说明用同一套。改动会马上显示，并在下次打开时保留。
2. 打开侧边栏时，「SOP标题」直接写成当前网页识别到的标题。改过之后就用你写的，网页标题不再盖掉它。把 SOP 标题清空，又回到网页标题。还没有标题时，视频里不再写「未命名流程」。说明默认是这个页面的介绍。介绍优先用网页自己的描述，没有描述时用正文开头的一段话。网页地址写在这段说明里，不写在每一步下面。你改过说明之后，就保持你写的内容。没有步骤时点「开始录制」，已有步骤时点「继续录制」，新步骤接到最后。某一步上的「在此后续录」会把新步骤接在这一步后面，前面改过的文字和截图保留。录下来的是一步一步可改的操作，不是一整段连续画面。
3. 在网页上把流程走一遍。密码框只记录「输入密码」，不记录内容。
4. 点「完成录制」。可以改标题和每一步的文字、调整顺序、删除。截图按屏幕原清晰度保存。点击某一步的截图，会打开大弹窗涂抹马赛克，点「完成」后这一步的图会换上涂好的结果。输入步骤可以点「涂掉输入」，只遮这一步的输入框。点「一键隐私」会把同一页每张截图里录到的输入框打上马赛克，并把步骤标题里的输入内容改成「已隐藏」。
5. 「复制文字」得到纯步骤。「下载 Markdown」得到一个 zip：里面是 `.md`，截图文件名是「流程标题+步骤标题」，例如 `images/上传失败+点击「AI 视频翻译」.jpg`。改了步骤标题后再导出，文件名会换成新的步骤标题。同名步骤会在后面加上步骤序号。「下载 PDF」按所选纸张出文件，页面按印刷清晰度绘制。版式是淡紫色正式文档。每一步左边是标题和说明，右边是完整截图，三者顶对齐，截图不会拉得过高。页脚有页码。文末落款可以自己写，留空就不显示。纸张可选 A3、A4、A5、B5、Letter、Legal，方向可选纵向或横向。一步超过一页时，后面按同一尺寸续页。底部「每页步骤」填 1 时，一步占一页，放不下会续页。填 2 到 20 时，这一页就排这么多步，截图缩小后放进同一页。「商标」默认使用智马翻译的文字商标，也可以另上传 PNG、JPG、WEBP、GIF 或 SVG。水印同样可以上传这些格式，并选择左上到右下九个位置之一，也可以不显示。水印还可以调大小和浓淡。商标盖在水印上面，每一页都会出现。还可以用「图片」滑块把截图调到页宽的 30% 到 100%，图片在页面里居中。流程标题和步骤标题可以分别改颜色、字号、粗细和位置，位置可选靠左、居中、靠右。总标题下面可以按需要写上录制时间和涉及的网址。说明也可以单独改颜色、字号和粗细。段距是标题、说明和截图之间的空白，行距是同一段里换行后的空白。样式会记住，下次导出仍然用这一套。流程标题只在第一页。中文和带橙色圆点的截图都在页面里。「下载 HTML」是淡紫色单文件，页首有商标，不压在步骤上。PDF 的商标也放在页眉，不盖住标题和步骤。「预览」在新标签打开网页版。「PDF 预览」按当前样式生成每一页，可以前后翻页，也可以下载这一份。「下载视频」按当前步骤生成。每一帧最上面是流程标题。步骤画面左边是这一步的标题和说明，右边是完整截图。改过步骤后再下载，视频会换成新的内容。

快捷键：Mac 为 Command+Shift+Y，Windows 为 Ctrl+Shift+Y。

页面上不放录制按钮，避免按钮被截进图里。每一步都会截当前画面，并把点击位置画成橙色圆点，圆点在图片里面，导出后还在。输入、下拉和勾选标记的是该控件的中心。正在录制时，工具栏图标上会显示已记录的步数。单次最多 100 步。

截图需要网站访问权限。在 `chrome://extensions` 里打开本插件的详情，网站访问权限选「在所有网站上」。改完后点重新加载。
