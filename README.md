# SOP 录制

Chrome / Edge 插件。在网页上照常点击、输入、跳转，自动生成带截图的步骤文档。

录的是浏览器里的页面，例如智马翻译工作台。微信、桌面软件不在录制范围内。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 打开「开发者模式」。
3. 选「加载未打包的扩展程序」，指向本目录 `sop-plugin`。
4. 把插件固定到工具栏。

## 使用

1. 点工具栏图标，打开侧边栏。录制、说明和导出按钮固定在最下面，步骤列表在上面滚动。「侧边栏样式」可以换纸色、浅色、深色或高对比，也可以改背景、文字、强调色、字号、间距、行距和圆角。标题和说明各自有颜色、字号和粗细，流程标题和每一步的标题用同一套，流程说明和每一步的说明用同一套。改动会马上显示，并在下次打开时保留。
2. 打开侧边栏时，标题默认是当前网页的标题，说明默认是这个页面的介绍。介绍优先用网页自己的描述，没有描述时用正文开头的一段话。你改过标题或说明之后，就保持你写的内容。点「开始录制」。
3. 在网页上把流程走一遍。密码框只记录「输入密码」，不记录内容。
4. 点「完成录制」。可以改标题和每一步的文字、调整顺序、删除。输入步骤可以点「涂掉输入」：文字改成「输入密码」，截图里这个输入框的位置打上马赛克。
5. 「复制文字」得到纯步骤。「下载 Markdown」得到一个 zip：里面是 `.md`，截图文件名是「流程标题+步骤标题」，例如 `images/上传失败+点击「AI 视频翻译」.jpg`。改了步骤标题后再导出，文件名会换成新的步骤标题。同名步骤会在后面加上步骤序号。「下载 PDF」按所选纸张出文件。纸张可选 A3、A4、A5、B5、Letter、Legal，方向可选纵向或横向。一步超过一页时，后面按同一尺寸续页。还可以用「图片」滑块把截图调到页宽的 30% 到 100%，图片在页面里居中。标题和说明可以分别改颜色、字号和粗细。流程标题用「字号」，每一步的标题用「步骤字号」。段距是标题、说明和截图之间的空白，行距是同一段里换行后的空白。样式会记住，下次导出仍然用这一套。流程标题只在第一页。中文和带橙色圆点的截图都在页面里。「下载 HTML」是带截图的单文件。「预览」在新标签打开。

快捷键：Mac 为 Command+Shift+Y，Windows 为 Ctrl+Shift+Y。

页面上不放录制按钮，避免按钮被截进图里。每一步都会截当前画面，并把点击位置画成橙色圆点，圆点在图片里面，导出后还在。输入、下拉和勾选标记的是该控件的中心。正在录制时，工具栏图标上会显示已记录的步数。单次最多 100 步。

截图需要网站访问权限。在 `chrome://extensions` 里打开本插件的详情，网站访问权限选「在所有网站上」。改完后点重新加载。
